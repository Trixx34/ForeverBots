# Rules R-V2-04 to R-V2-08 (2026-10-11)

Implemented behind settings in `botserver.conf.dist` (section Bot.Rules.*). All default to on and respect `Bot.Rules.ArmPct`. Status: built, not run in game, unmeasured. The next sim run decides whether each stays.

| Rule | Settings | Log rows |
|---|---|---|
| R-V2-04 free bag slots | `Bot.Rules.BagFree.Enabled/TargetFreeSlots/RetryCooldownSec` | `BAG_FREED`, `BAG_STILL_FULL` (blocked, with bag breakdown), `VENDOR_RETRY_WAIT`; `VENDOR_RESULT` gains `extra_candidates`, `extra_sold` |
| R-V2-05 death loop breaker | `Bot.Rules.DeathLoop.Enabled/Deaths/WindowSec/AreaYards/BlockSec/SharedBots/SharedSec` | `DEATH_LOOP_BLOCK` (warn); `NO_GRIND_TARGET` gains `shun_skips`, `shun_blocks` |

| R-V2-07 target pick | `Bot.Rules.TargetPick.Enabled/MaxAbove/GreyBelow/MinXp` | `TARGET_SKIP_LOW_XP` (at most one per 2 min per bot) |
| R-V2-08 quest filter | `Bot.Rules.QuestFilter.Enabled/BlockedQuests/UnsupportedObjectives/LevelSlack/GlobalQuarantineSec/LocalFails` | `QUEST_FILTERED`, `QUEST_LEVEL`; quarantine rows use the configured values |

## Limits
- R-V2-04: sells only, no destroy. The extra pass handles poor/white weapons, armor and junk misc items that are no gear upgrade and not quest items; trade goods and consumables are untouched.
- R-V2-05: "move to a lower-level area" is done by skipping the killer entry and the blocked circle in grind scans and by resetting the task and blacklisting the quest. Quest legs through the area are not filtered by geometry. The shared avoid list applies to grind target scans only.
- R-V2-06: only stops fleeing when escape is impossible; no defensive cooldown or bandage logic.
- R-V2-07: candidate radius is the existing scan range; elite XP is not modelled; the level cap was effectively already 1.
- R-V2-08: the usual level check stays on, `LevelSlack` can only tighten it. Unsupported objectives were already blocked by the classifier (`OBJECTIVE_UNSUPPORTED`); the filter adds optional criteria-tree objectives.
