# Rules v4 (2026-10-12)

Owner-approved rules from `run-1000bot-30m-analysis-20261012.md`. Every rule has a switch and defaults to ON. Settings are in `src/server/worldserver/botserver.conf.dist` and loaded in `BotRules.cpp`. Like the other `Bot.Rules.*` rules they honor `Bot.Rules.ArmPct` (A/B arms) where noted by `BotRules::Applies`.

| Rule | What it does | Options (default) |
|---|---|---|
| R-V4-01 | Priest, mage and warlock bots up to level 4 skip targets more than 1 level above them (elite bonus counts) and targets with another hostile creature within 10 yards. Checked in `CandidateMob` (grind and quest kill targets). | `Bot.Rules.CasterSafe.Enabled` (1), `.MaxLevel` (4), `.MaxAbove` (1), `.PackYards` (10) |
| R-V4-02 | The low-health flee starts at 35% instead of `Bot.AI.Combat.Flee.LowHpPct` (15) while 2 or more creatures attack the bot. Flee budget and the about-to-win exception are unchanged; the `limit_pct` field of the flee row shows the threshold used. | `Bot.Rules.MultiFlee.Enabled` (1), `.HpPct` (35), `.Attackers` (2) |
| R-V4-03 | `quest_blocked` rows: once per bot and quest, then at most once per interval for that bot and quest (any code). 0 = old behavior. | `Bot.Log.QuestBlockedIntervalSec` (600) |
| R-V4-04 | Quests 170, 4402, 805, 789, 6394 are added to the default `Bot.Rules.QuestFilter.BlockedQuests`. 789 was on the default `NeverBlock` list, which overrides the blocklist, so it was removed from `NeverBlock` (new default `404,112,792,380,488,92544`). | `Bot.Rules.QuestFilter.BlockedQuests` (`794,5441,1656,3905,47,400,2160,170,4402,805,789,6394`), `Bot.Rules.QuestFilter.NeverBlock` |
| R-V4-05 | Creature entries 3125, 1526, 1525, 706 are avoided (same effect as `Bot.AI.Avoid.Entries`) when more than 2 levels above the bot. | `Bot.Rules.AvoidMobs.Enabled` (1), `Bot.Rules.AvoidMobs` (`3125,1526,1525,706`), `.LevelMargin` (2) |

## Start gear switch

`Bot.StartGear.Enabled` (default 1) already existed. With 0, `BotAI::RunStartGear` returns before `BotStartGear::Grant`, and `Grant` itself also returns when disabled, so no `START_GEAR` or `START_GEAR_NONE` row is written and no item is granted (both the LOGIN and the LEVEL pass). Use it for the gear A/B test; items already granted stay on the characters.

## Notes

Configs are read once (hot reload applies through the existing reload mechanism). Rule 1 only runs the neighbor scan for casters of level 4 or lower, so the per-tick cost for other bots is zero.
